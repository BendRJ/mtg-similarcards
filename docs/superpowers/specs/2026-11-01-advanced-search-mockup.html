Guesses:

  • Fields: Rules text, Type, Color. I also added Name contains (your query has it commented out).
  • Operators: text uses "contains" or "does not contain", case-insensitive. Type uses "is" or "is not", from a fixed list (Artifact, Battle, Creature, Enchantment, Instant, Land, Planeswalker, Sorcery, Kindred), and "is Land" matches any card whose type line includes Land. Color uses "has any of", "has all of" or "has none of", with C meaning colorless.
  • Page: a separate page at /search, linked from the top bar. The home search bar stays as it is.
  • Filters in the URL: a search can be bookmarked or shared and survives a reload.
  • Sort: by name (default), mana value ascending, or mana value descending.
  • Results: same grid and tiles as the set page, only real game cards (no tokens), limited to the first 200 matches with a count shown.
